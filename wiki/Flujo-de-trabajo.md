# Flujo de trabajo

1. Crear una rama independiente para cada tarea a partir de `develop`.
2. Implementar y revisar la tarea en esa rama.
3. Abrir un Pull Request de la rama de tarea hacia `develop`.
4. Fusionar cada PR de tarea en `develop`.
5. Cuando todas las tareas estén terminadas, abrir un único PR de `develop` hacia `main` y fusionarlo.

No se usan GitHub Issues ni GitHub Projects en esta práctica.
