# API del almacén de papelería

Servicio REST desarrollado con Spring Boot y Java 21 para consultar artículos de un almacén.

## Contenido

- [API y endpoints](API-y-endpoints)
- [Base de datos y ejecución](Base-de-datos-y-ejecucion)
- [Flujo de trabajo](Flujo-de-trabajo)

La aplicación permite consultar todos los artículos, obtener la información básica de uno, indicar cuándo está agotado y responder con HTTP 404 si no existe.
